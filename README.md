# CodeAlpha Internship - Task 3: Data Visualization Dashboard

## 📌 Project Overview
This project transforms raw Titanic dataset records into a clear, multi-panel visual dashboard as part of the CodeAlpha Data Analytics Internship. It utilizes data visualization storytelling techniques to reveal multidimensional trends and insights regarding passenger demographics and survival outcomes.

## 🛠️ Tools & Libraries Used
- **Python**
- **Pandas** - Data preparation and wrangling
- **Matplotlib** - Figure layout and multi-plot subplots
- **Seaborn** - Advanced statistical charts and visual styling

## 📊 Dashboard Visualizations Included
1. **Overall Survival Count:** Displays the total distribution of passengers who survived versus those who did not.
2. **Survival Probability by Gender:** Highlights the disparate survival rates between male and female passengers.
3. **Survival Rate by Passenger Class & Gender:** Examines the multi-variable intersection of socio-economic class, gender, and survival likelihood.
4. **Age Distribution Profiling:** Compares the KDE and histogram age distributions of survivors versus non-survivors.
